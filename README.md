To-Do List
Aplicación web sencilla para gestionar tareas pendientes. Utiliza localStorage para persistir los datos en el navegador, sin necesidad de base de datos ni backend.

Tecnologías Utilizadas

HTML5
CSS3
JavaScript (Vanilla)
localStorage 

Funcionalidades

 Agregar nuevas tareas
 Marcar tareas como completadas
 Eliminar tareas
 Persistencia de datos con localStorage 

 ¿Cómo funciona el localStorage?
Las tareas se guardan automáticamente en el navegador cada vez que se agregan, completan o eliminan. Al recargar la página, los datos se recuperan desde localStorage para que no se pierda ninguna tarea.
